# 从问题到图形

四套看板沿用相同的操作逻辑，但各自围绕独立问题组织内容。顶部用于定位观察期，中部比较规模、结构与变化，末尾提供明细与导出。来源和口径放在独立窗口，图面集中呈现数据。

|主题|主要问题|对应图形|可比较内容|
|---|---|---|---|
|季度经济|增长规模与增长动力是否一致|GDP柱线、产业堆叠、需求贡献|现价规模、实际同比及官方贡献率分别解读|
|季度经济|行业之间差异有多大|排名、气泡、时间热力、斜率|同一期增速差异及不同时点变化|
|旅游住宿|客流恢复是否带来相同消费增长|柱线、2019基期指数、城乡花费折线|总人次、总花费与每人次花费|
|旅游住宿|供给与国际客流怎样变化|镜像柱线、客源排名、供给基期指数|入出境人次、列示国家及星级住宿供给|
|教育发展|学段规模与资源是否同步|堆叠面积、矩形树、平行坐标、气泡|六类在校生、专任教师和学校数|
|教育发展|资源来源与投入强度如何变化|来源堆叠、百分比面积、经费/GDP|全国经费，避免与所选六类学段混算|
|人口民生|人口结构与居民生活如何变化|年龄结构、抚养比、收入斜率|城乡人口、年龄与城乡收入差异|
|人口民生|消费结构是否改变|收入消费组合、消费矩形树、恩格尔系数|同单位金额与结构，避免把金额当实际增速|

同比矩阵补充年度变化；相关矩阵比较共同变化方向和强度。两者不替代机制分析。旅游国际收入缺失较多，相关系数的共同观测数随指标对而变化，因此提示框同时显示n。季度分析直接使用官方实际增速，避免用名义金额倒算实际增速。

筛选的目的不同。观察期决定卡片和截面图，区间决定趋势和相关样本，教育学段决定分类图与所选合计。图形使用实际公布年份的情况会显示年份标记，例如观察2025年时，国际旅游收入构成仍可能展示2019年。

可按以下顺序演示：切换四个主题，观察最新指标；将观察期移到2020年比较旅游需求变化；在教育中保留一个学段，查看招生毕业与教师资源；回到季度经济切换累计，再缩短区间；最后打开单图并导出当前期数据。
