# 第三方资源

本项目随包提供 Apache ECharts 浏览器发行文件 assets/echarts.min.js，用于离线绘图。版权所有者为 Apache Software Foundation 及贡献者，适用 Apache License 2.0，发行文件原始许可头完整保留。许可全文与NOTICE分别置于 assets/ECHARTS_LICENSE.txt、assets/ECHARTS_NOTICE.txt。

官方项目：https://github.com/apache/echarts

Python构建依赖为pandas及openpyxl，由使用者通过其官方包安装。统计数据来自国家统计局国家数据公开查询；其来源、日期与处理方式记载在数据清单中。页面未打包用户参考截图、浏览器账号、登录信息或其他课程资料。
