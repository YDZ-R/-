# 国家数据四主题驾驶舱

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

延续已完成课程作业的 Python 数据整理、ECharts 原生交互和静态 HTML 交付。交付目录可离线打开；不依赖账号、数据库服务或前端构建工具。

## Users

曹俊男的可视化课程新作业，供本人演示和教师查看。主要使用桌面浏览器，也支持手机浏览。

## Product Purpose

以国家统计局国家数据公开统计为基础，完成四个可独立打开的大型交互看板：国民经济季度运行、旅游与住宿、教育发展、人口与民生。统一入口连接四个主题，完整数据、代码和成果归档到用户指定的 GitHub 仓库。

## Operating Context

参考用户提供的三张大型看板截图：清爽浅色、青蓝色系、顶部筛选与指标、下方多组图形，支持年份播放与图表联动。沿用之前课程中柱线组合、堆叠面积、蝴蝶、滑珠、环形、热力、矩形树、平行坐标及统计分析知识。

## Capabilities and Constraints

- 来源入口为 https://data.stats.gov.cn/dg/website/page.html#/pc/national/home 。
- 不编造、补齐未公布的年份；缺失值和口径变化在数据及界面中保留。
- 年份/季度、起止区间和分类筛选需联动；提供播放、重置、详细数据导出和单图放大。
- 图内保留标题、图例、单位、必要标签。数据来源、口径和操作说明集中在可展开面板和文档，避免堆在图里。
- 原始表、处理数据、Python代码、离线资源、截图和使用说明一起打包。
- GitHub目标：https://github.com/YDZ-R/- 。新作业置于独立“国家数据可视化看板”目录，保留既有三个课程目录。
- 具体时间范围以实际可核验的官方数据为准。

## Brand Commitments

视觉以用户提供的季度GDP、教育十五年、旅游十五年参考截图为准。采用适合课堂投影的浅色背景、深色正文和青蓝主色，兼顾密集图表的阅读。
