# 商业数据分析教材精选实验

曹俊男 · 大数据241 · 2024459985112

本次平时作业从《CDA 教材资料2025》四套材料中分别选取5项，共20个实验、40张Python结果图。选题分散在各套教材的不同章节，覆盖经营分析、数据治理、统计与分群、关联规则、反欺诈、预测、运筹和金融案例。规模参照既有可视化作业的30张静态图、动态图表和看板综合安排，不以重复导出相同代码凑数量。

一级教材的5项将Excel/PowerBI/SQL分析思路迁移到Python。其余15项从原Notebook选取有业务含义的核心实验，形成可独立运行的.py，保留数据口径并修复路径、旧库、随机性及数据泄露问题。每个实验README解释方法、参数、所选范围、转换差异和实际结果。

## 运行

已验证Windows、Python 3.13。固定依赖要求Python 3.11及以上。

```bash
python -m pip install -r requirements.txt
python run_all.py
```

只运行指定实验：

```bash
python run_all.py --only 01 08 15
python verify.py
```

从任意工作目录运行均可，输入与输出使用脚本相对路径。全部正式实验使用归档数据，运行过程不联网，不需要MySQL账号、CPLEX、toad、Orange、jupyter或GPU。中文绘图优先使用微软雅黑、黑体或Noto Sans CJK；其他系统需安装可用中文字体。

`common.py`只共享文件读写、字体与基础绘图；每项实验的特征、聚合、模型及验证保留在自己的`实验.py`。PNG为200 dpi，CSV为UTF-8 BOM，完整参数与指标保存在各自outputs/results.json。运行核验.json记录来源哈希、脚本语法、结果文件与图片分辨率检查。

## 数据与范围

全部输入来自用户提供的教材配套材料，不以随机生成数据代替教材案例。sources.json逐项记录原始归档路径、字节数和SHA-256。第13项原信用卡文件约151MB，按Class分层、种子241抽60000条并保持原始行号，发布子样本及其独立哈希。其他所选原始文件原样保存。

分类实验先分训练与测试，填补、缩放、分箱和参数选择仅学习训练数据。时间序列最后12个月留出，不参与选型。分群为探索性画像；标签编号不直接代表高低价值。金融风险与营销结果仅用于教材学习，不是实际授信或客户经营决策。

本次没有覆盖整套教材的每个章节，也没有运行所选Notebook的全部扩展算法。第18项以显式WOE分箱替代toad，第19项选取行为聚合与逻辑回归。原方法、数据与教材材料归原作者，当前仓库说明转换和改写范围。OpenAI Codex参与选题、代码整理、运行核验及说明撰写。
